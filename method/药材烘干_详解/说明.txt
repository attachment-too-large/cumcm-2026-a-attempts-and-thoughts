这份文件说明文件夹里有什么，以及怎么把它变成 PDF。

============================================================
一、这个文件夹里是什么
============================================================

这里是一份写给零基础读者的讲解文档的 LaTeX 源码，
内容是 2026 年数学建模竞赛 A 题药材烘干问题的数学推导与代码解释。

文件清单：

  编译.bat        双击这个文件就能编译，见下面第二节
  详解.tex        主文件，负责排版设置和把四个部分拼起来
  part1.tex       第一部分，数学与物理基础，约 880 行
  part2.tex       第二部分，数值方法原理，约 1630 行
  part3.tex       第三部分，代码逐行解释，约 770 行
  part4.tex       第四部分，如何确认结果正确，约 550 行

全文合计约 3900 行。

============================================================
二、怎么生成 PDF
============================================================

方法一，双击 编译.bat

  这个批处理会自动做四件事：
    1. 检查电脑上有没有装 xelatex
    2. 连续编译两遍（第一遍生成目录，第二遍修正页码）
    3. 把生成的 PDF 复制到桌面
    4. 暂停，让你看清楚结果

  如果提示找不到 xelatex，说明还没装 LaTeX。
  需要先安装 MiKTeX 或者 TeX Live，装完再双击一次。

方法二，手动敲命令

  打开 PowerShell，输入下面两行：

    cd "C:\Users\qing1\Desktop\药材烘干_详解"
    xelatex 详解.tex

  第一遍跑完后，再按一下键盘上箭头键调出上一条命令，
  再回车跑第二遍。
  第二遍必须跑，否则目录里的页码和正文里的公式编号会是问号。

  生成的文件叫 详解.pdf，就在这个文件夹里。
  自己手动复制到桌面即可。

============================================================
三、需要装什么
============================================================

LaTeX 发行版，二选一：

  MiKTeX        体积小，缺什么宏包会自动联网下载，适合新手
  TeX Live      体积大，一次装全，适合网络不好的情况

编译必须用 xelatex，不能用 pdflatex。
原因是要处理中文，pdflatex 对中文支持不好。

本文件用到的宏包：ctex、amsmath、amssymb、geometry、graphicx、
booktabs、multirow、longtable、array、enumitem、xcolor、
listings、caption、float、hyperref。
其中 ctex 是处理中文的关键，MiKTeX 第一次用到时会自动下载。

============================================================
四、如果编译报错怎么办
============================================================

编译时会生成一个 详解.log 文件，里面记录了全过程。

查找错误的方法：用记事本打开这个文件，
搜索以感叹号开头的行，那些就是错误。

常见的三种错误和对策：

  1. 提示缺少某个 .sty 文件
     说明宏包没装齐。MiKTeX 一般会自动下载，
     如果没自动下载，可以在 MiKTeX Console 里手动安装。

  2. 提示 File `ctex.sty' not found
     同上，是 ctex 宏包缺失。

  3. 提示字体找不到
     说明系统缺少中文字体。
     本文件用的是 Windows 自带字体，正常情况不会出这个问题。

============================================================
五、这份文档讲了什么
============================================================

第一部分从最基础的东西讲起：偏导数是什么、怎么算，
守恒律怎么变成微分方程，边界条件有哪三类，
最小二乘拟合是怎么找到最优参数的。
这一部分把从物理规律到两个控制方程的每一步代数运算都写全了。

第二部分讲为什么这道题不能用公式直接算，
重点讲三件事：坐标变换怎么把圆心处的除以零消掉，
谱方法怎么用很少的点算得很准，
时间方向为什么必须用隐式方法。

第三部分把程序逐行讲一遍，
包括每个 numpy 函数在做什么、每个公式对应代码里的哪一行、
为什么边界条件要单独赋值。

第四部分讲怎么判断结果对不对，
包括与精确解比较、网格加密、用三种不同方法互相验证，
以及灵敏度分析的结果怎么读。

另外还有两处专门为初学者加的内容：
  第二部分第九章  问题四的收缩推导，从材料坐标讲到最后的结果换算
  第二部分第六章  一个三节点的手算例子，可以拿计算器复核每一步
