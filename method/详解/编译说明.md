# 编译说明

本目录是讲解教材《药材烘干问题的数学推导与代码解释》的 LaTeX 源码，
编译产物就是同目录的 `详解.pdf`（**184 页**）。**源码与 PDF 一一对应**，
修改任一 `part*.tex` 后重新编译即可得到更新后的教材。

## 六部分的分工

| 部分 | 文件 | 内容 |
| --- | --- | --- |
| 主文件 | `详解.tex` | 导言区、样式定义、六个部分的 `\input` |
| 第一部分 | `part1.tex` | 数学与物理基础：偏导数、圆柱坐标、守恒律、两个控制方程 |
| 第二部分 | `part2.tex` | 数值方法原理：坐标正则化、谱配置、边界条件处理、时间推进 |
| 第三部分 | `part3.tex` | 代码逐行解释：13 个 Python 模块 |
| 第四部分 | `part4.tex` | 结果验证：三族互证、闭式解基准、灵敏度 |
| 第五部分 | `part5.tex` | 其余程序逐行解释：两套对照格式、结果文件、插图体系、受控对照、产出链 |
| 第六部分 | `part6.tex` | 问四闭式解的完整推导 |

## 编译方法

需要 MiKTeX 或 TeX Live，用 `xelatex`：

```bash
cd method/详解
xelatex -interaction=nonstopmode 详解.tex
xelatex -interaction=nonstopmode 详解.tex
xelatex -interaction=nonstopmode 详解.tex
```

**必须连续编译到目录稳定，中途不要删 `详解.toc`。**

原因：本文档的目录本身有 9 页，目录长度会反过来影响正文起始页，
进而影响目录里记录的页码。如果第一遍没有 `.toc`，正文会从第 4 页开始，
这个错误的页码会被写进 `.toc`；第二遍目录撑开、正文推到第 12 页，
页码才被纠正。**判据是日志里不再出现 `Label(s) may have changed`**——
三遍之后该警告消失，此时 `.toc` 收敛，目录页码与书签完全一致。

## 关于文中的数字

教材里部分「复跑报告」数字取自较早一次运行（`run_all.py` 未重跑，
完整复跑约需 6.5 分钟且依赖赛题附件）。这些数字与该次运行的输出一致，
但**不是本次编译前实测复算的结果**；如需彻底核对，重跑 `run_all.py` 后逐项比对即可。
