# 版本说明

## 本目录两份东西的关系

| 文件 | 版本 | 说明 |
| --- | --- | --- |
| `详解.pdf` | **最新修订版（149 页）** | 最新的一份，代码部分已按最终交付包重写 |
| `part1.tex` — `part6.tex`、`详解.tex` | **上一修订版（146 页）** | 生成 146 页版本 PDF 的源码 |

**两者不完全对应。** `详解.pdf` 是从更新后的 `part3.tex` 与 `part5.tex` 编译出来的，
而本目录里的这两个文件还是上一修订版。

## 差在哪里

最新修订版相对上一版做了这些改动：

**`part3.tex`（第三部分 代码逐行解释）**

- 文件清单从 12 个改为 13 个，按「基础 / 求解器 / 驱动」三类重排
- 按最终交付包的实际代码重写：补上 `Np`、`r_nodes`、`_bary_weights`、`area_weights`
  的逐行解释；补上重心插值里两处防御性写法（命中判据用相对容差、分母为零时兜底）
- `common.py` 一节补上 `VARIANTS`、`C_FLOOR`、`T_END`、`bessel_roots`，
  并新增「两种 RMSE 口径」一节
- `analytic_p1.py` 一节按最终版更新（系数 B 改为函数内部计算，不再是模块常量）
- 把 `env_compare.py` 一节换成 `verify_data.py` 与 `console_utf8.py`

**`part5.tex`（第五部分 其余程序逐行解释）**

- 部分标题改为「其余程序逐行解释」，与目录一致
- 代码行号引用全部更新为最终交付版的行号
- 插图体系一节由 `make_figs.py` / `make_fig3.py` 换为
  `fig_core.py` / `make_figures.py`，整节重写
- 新增「受控对照 `make_controlled_comparison.py`」一节
- 产出链由 4 步改为 5 步
- **追赶法」一节展开写细**：
  - 3×3 手算例子拆成四个分步框，每步写出中间结果，补上中间量汇总表与符号陷阱提醒
  - 「为什么不需要选主元」扩写成完整证明：严格对角占优的定义、命题陈述、
    四步归纳法（起点 / 归纳假设 / 估计分母 / 占优收口）、手算对照、
    以及新增一节「顺带看清误差是怎么往回传的」

## 为什么源码没同步

更新后的 `part3.tex` 与 `part5.tex` 只存在于一个临时工作目录里，
该目录后来被清理，源码随之丢失。`详解.pdf` 因为单独导出过所以保留了下来。

## 如果需要一致

两条路：

1. **按本目录的源码重新编译**，得到 146 页版本 —— 内容与源码完全对应，
   但缺少上面列出的更新。
2. **把上面列出的改动重新做一遍** —— 需要重新编写 `part3.tex` 与 `part5.tex`
   的对应小节；改动清单已在本文档中列全，可以照着做。

在此之前，请以 `详解.pdf` 为准（它是最新内容），
但不要直接用本目录的 `part*.tex` 期望编译出一模一样的 PDF。
