1 方法 B：材料坐标 + 分级谱元弱形式 Galerkin

1.1 与题面一致的物理模型（与工作区 M0 代数等价）

以 σ = r/R(t) 为材料坐标（均匀仿射收缩），均匀收缩下 Eulerian 方程里的对流项精确抵消：

ρ(C)c_p(C) ∂T/∂t = (k(C)/R²)·(1/σ)∂_σ(σ ∂_σ T)
∂C/∂t           = (D(C,T)/R²)·(1/σ)∂_σ(σ ∂_σ C)
σ=1:  -k(1/R)∂_σT = h(T-T_∞) ,  -D(1/R)∂_σC = h_m(C-C_∞)
σ=0:  正则（弱形式自动消解 1/σ 奇异）

工作区 M0 用干物质坐标 s 与 J(s) 写成 ∂C/∂t=(4I²/R²)∂_s((JD/v²)∂_sC)；在 v≡v₀ 时令 s=σ² 可代数化为上式（本文已逐项验证），所以两者是同一个数学模型，差异只在数值方法。

1.2 离散：为什么用「偶数 Legendre 谱」+「分级谱元」

  • 偶数 Legendre 模态基 φ_j(σ)=P_{2j}(2σ-1)：质量矩阵解析对角 M_jj = 1/(2(4j+1))（数值验证误差 2e-15，条件数 ≈ 4N），σ=0 的柱心奇异项被弱形式自动吸收，φ_j(1)≡1 使表面值就是系数和（两端点精度不受端点 Gibbs 影响）。
  • 全局多项式基在表面薄边界层上会产生振铃下冲 → e^{-a/C} 在 C<0 时爆炸 → 非线性失稳。因此改用分级谱元：把最外层单元放在边界层上。
  • 弱形式 + 自然 Robin 边界：取检验函数 φ₀≡1 时 1ᵀA≡0 精确成立，于是 d/dt ∫ρc_pTσdσ = -(h/R)(T_s-T_∞)、d/dt ∫Cσdσ = -(h_m/R)(C_s-C_∞) 在离散层面精确成立（实测差 2e-8，等于质量矩阵条件数与机器精度的乘积）。

2.1 【最关键】三处 D 公式的指数是分式，不是乘积

A题.pdf 的文本抽取把竖排分式压平成一行：

问题2/3: D = 2.4×10⁻³ · e^(−0.45/C) · e^(−3850/T)

后果是量级级别的：

读法 C=2.55 时 D C=0.15 时 D 随干燥的变化 问题 3 烘干时长
e^{−0.89·C}（误） 7.2e-10 6.1e-9 增大 8 倍 16.44 h

paper_tools/md2pdf.py 是为出 PDF 自建的轻量排版链路： Markdown →（markdown_it 解析，公式先占位保护）→ HTML + CSS（A4、三线表、图题注、防分页）→ MathJax 3 渲染公式 → 无头 Edge --print-to-pdf 打印 → PyMuPDF 加页脚页码。 不依赖 pandoc / LaTeX / weasyprint，纯离线可复现。
