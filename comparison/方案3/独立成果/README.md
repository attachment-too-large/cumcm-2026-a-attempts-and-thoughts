## 2. 方法与主要结论

### 2.1 方法要点

**坐标正则化 `u = (r/R)²` + Chebyshev 谱配置 + 自适应高阶隐式积分 + Bessel–Duhamel 闭式解**

1. **坐标**：取 `u = ξ² = (r/R)²` 为自变量，使圆柱 Laplace 算子
   ```
   (1/r) ∂/∂r ( r·D·∂/∂r )  =  (4/R²) ∂/∂u ( u·D·∂/∂u )
   ```
   在 `u = 0` 处**完全正则**。常规 `r` 坐标离散必须把最内控制体取成 `[0,h/2]`
   并令其测度为 `h²/8`，本方法不需要任何特殊处理。
2. **空间**：Chebyshev–Gauss–Lobatto 谱配置。解在 `u` 上解析，故谱收敛成立；
   实测 **N = 8 即达 10⁻¹⁰**。
3. **时间**：变阶变步长隐式 BDF，物性在每步重新计算，误差由 `rtol/atol` 控制。
4. **问题 1 温度场**：常物性 + 指数升温环境 ⇒ 准静态分解给出**闭式级数解**，
   **2 项即达机器精度**，完全不需要空间离散。
5. **问题 4 收缩**：物质坐标下严格推导，对流项为零；并证明在固定 `r` 坐标下
   **不能**直接写扩散方程（须补 `−Ṙ·r·∂_rC/R`）。

## 4. 方法与出处说明

为保证工作可核查，此处明确本文的贡献边界：

**属于题目给定的（非本文提出）**
* 物理模型：圆柱一维轴对称热传导方程、Fick 扩散方程、表面 Robin 对流边界条件；
* 初始条件（28 °C、2.55 kg/kg）与全部传递系数（h = 25、h_m = 8×10⁻⁷）；
* 附录 2–4 的三组物性经验式；
* 几何与工艺条件、烘干判据（各处水分浓度 < 0.15 kg/kg）；
* 附件 1 的环境数据与附件 2 的收缩半径数据。

**属于本文的建模选择**
* 把附件 1 的实测环境标定为一阶惯性式 `T_air(t) = T_set − (T_set−28)e^{−t/τ_T}`
  （Levenberg–Marquardt 二参数拟合，初值固定为实测值，RMSE 0.3359 °C，R² = 0.9957；
  湿度同法，RMSE 8.08×10⁻⁴，R² = 0.9901）；
* 据附件 1 在 t ≈ 4 h 达到稳定，把工艺分为预热平衡段（0–14400 s）与恒温干燥段；
* 烘干时长判据取「全场节点最大含水率首次跌破 0.15」的时刻。

**属于本文的推导与实现（代码全部自行编写）**
* `u = (r/R)²` 坐标正则化变换及其在谱方法中的应用；
* 问题 1 温度场的 Bessel–Duhamel 闭式解（含准静态分解与特征函数展开的完整推导）；
* 问题 4 物质坐标下对流项为零的推导，及固定 `r` 坐标下不可直接写扩散方程的证明；
* Chebyshev 谱配置的**通量形式**边界处理；
* 用自适应高阶隐式积分替代定步长 θ 法，以及由此得到的烘干时长收敛性结论；
* 三套相互独立的求解器（谱配置、节点中心 FV+θ、均匀网格守恒 FV）及其交叉验证。

**需要如实说明的一点**：本题的物理模型由题目给定，可自由发挥的空间主要在**数值方法层**；
不同解法在模型层必然趋同。因此本文的贡献定位于
**数值方法、闭式解与收敛性分析**，而非模型本身的新发现。
