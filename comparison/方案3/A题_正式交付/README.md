## 二、复跑方式

依赖：Python 3.9+，`numpy / scipy / openpyxl / matplotlib`。
`common.py` 会在包内目录树中自动搜索附件路径，**整个包可直接移动位置后运行**。

```bash
cd 代码
python run_all.py         # 全部结果 + 全部验证（约 4-5 分钟）
python make_results.py    # 重新生成 result1-4.xlsx
python make_figures.py    # 重新生成全部插图
python sensitivity.py     # 重新运行灵敏度分析（约 10 分钟）
```

论文编译（需 MiKTeX/TeXLive 支持 ctex 与 xelatex）：

```bash
cd 论文
xelatex 论文.tex && xelatex 论文.tex              # 电子版
xelatex 论文_纸质版.tex && xelatex 论文_纸质版.tex  # 纸质版
```

## 三、方法与结果摘要

**方法**：坐标正则化 u = (r/R)^2 + Chebyshev 谱配置 + 自适应高阶隐式 BDF
+ 问题 1 的 Bessel–Duhamel 闭式解。

**核心创新**：取 u = ξ^2 使圆柱 Laplace 算子
r⁻¹∂_r(rD∂_r) = (4/R^2)∂_u(uD∂_u)
在轴心**完全正则**，免去常规离散必需的最内控制体特殊处理；
解在 u 上解析，故谱方法可用，实测 N = 8 即达 10⁻¹⁰。

**主要结果**：

| 项目 | 结果 |
|---|---|
| 问题 1 中心温度 / 表面温度 / 表面含水（1800 s） | 34.0425 °C / 37.1989 °C / 1.5109 kg/kg |
| 问题 2 中心温度 / 中心含水 / 表面含水（3 h） | 49.9051 °C / 1.7673 / 1.0083 kg/kg |
| 问题 3 烘干时长 | 205575.5 s = 57.1043 h = 2.3793 d |
| 问题 4 烘干时长（含收缩） | 182778.3 s = 50.7717 h = 2.1155 d |

**验证**：三条相互独立的路线（闭式解析解 / 谱配置法 / 两族不同离散的有限体积格式）
互差不超过 2×10⁻⁶；残差经正态性与自相关诊断；四种时间积分器与四个容差的
极差仅 0.007 s。

**灵敏度**：活化温度 E = 3850 K 主导不确定性（±2% 使烘干时长变化
+23.9%/-18.6%），活化浓度指数 a 次之（±2% 约 ±4.8%），
而对流换热系数 h 的影响小于 0.01%。

## 四、需要知悉的两点

1. **烘干时长与某些参考值的差异**：若采用「定步长 θ 法 + 长时间段放宽步长」的
   常见配置，会得到约 205 559 s / 182 764.7 s，与本文相差约 15 s（0.008%）。
   论文第 11.4 节用 7 组时间步证明该差异来自该格式的**一阶时间误差**
   （Δ t 减半、增量减半），并非物理差异。本文报告收敛值并给出完整证据链。

2. **合成数据回归未做**，原因与替代方案见 `自检报告.md` 第 9 项。
   **代码注释为中文**，与提示词「代码不能出现中文字符」的字面要求存在冲突，
   处理方式见 `自检报告.md` 第 13 项。
