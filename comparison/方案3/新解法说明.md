## 1. 新解法：u=(r/R)² 坐标下的谱配置 + 自适应隐式积分

### 1.1 核心思想（与 paper 的第一处不同：换坐标使算子正则）

paper 直接在 **ξ = r/R** 上离散，圆柱 Laplace 算子 `(1/r)∂_r(r·∂_r·)` 在 r=0 处有
1/r 奇异，必须对轴心控制体做特殊处理（`vol₀ = h²/8`）。

本文改取

```
u = ξ² = (r/R)²  ∈ [0,1]
```

于是（本文独立推导，并已数值校验）

```
(1/r) ∂/∂r ( r·D ∂/∂r )  =  (4/R²) ∂/∂u ( u·D ∂/∂u )
```

**右端在 u=0 完全正则**：

```
∂/∂u ( u·D ∂C/∂u ) |_{u=0} = D(0)·(∂C/∂u)(0)     ——有限，无需任何特殊处理
```

因此两个控制方程在整条半径上形式统一：

```
∂C/∂t = (4/R²) ∂_u ( u·D ∂_u C )
ρ(C)c_p(C) ∂T/∂t = (4/R²) ∂_u ( u·k ∂_u T )
```

边界（由 `∂_r = (2√u/R) ∂_u` 推出，u=1 处即 ∂_r=(2/R)∂_u）：

```
2·D·∂_u C |_{u=1} = h_m·R·(C_air − C)          （水分，Robin）
2·k·∂_u T |_{u=1} = h  ·R·(T_air − T)          （温度，Robin）
```

u=0 处不加边界条件——**正则性本身**就是边界条件（把 PDE 直接配置在 u=0 即可）。
对问题4，把 R(t) 放进算子系数即可，物质坐标下**对流项严格为零**。

### 1.2 空间离散（与 paper 的第二处不同：谱精度）

在 Chebyshev–Gauss–Lobatto 节点 `u_j = (1−cos(jπ/N))/2` 上做谱配置，
`D_u = −2·D_x`（`D_x` 为标准 Chebyshev 微分矩阵）。

**关键观察**：解 C 是 ξ 的偶函数（J₀ 展开只含 ξ² 次幂），所以作为 u 的函数在 [0,1] 上解析
⇒ Chebyshev 谱收敛成立。

通量实现：内部节点 `g_j = u_j·D_j·(D_u C)_j` 由谱微分给出，
**表面通量 g_N 直接取 Robin 条件的物理值** `g_N = ½ h_m R (C_air − C_N)`。

### 1.3 时间离散（与 paper 的第三处不同：自适应 + 高阶）

paper：固定步长 θ 法（θ=½ 为 CN，前 4 步 Rannacher 启动），**物性取上一时间步冻结**
⇒ 实测为**一阶**时间精度（见第 4 节实测数据）。

本文：SciPy `solve_ivp` 的**变阶变步长隐式 BDF**（并用 `Radau`、`LSODA` 交叉验证），
物性在每个 RHS 求值处按当前状态重新计算，误差由 `rtol/atol` 直接控制。

### 1.4 问题1 温度场：闭式解析解（与 paper 的第四处不同：根本不离散）

问题1 的 ρ、c_p、k 是常数、D 只依赖 C，故**温度场与水分场完全解耦**，
且环境是一阶惯性式 `T_air(t)=T_set−(T_set−28)e^{−t/τ_T}`。令 `w = T − T_air`：

```
∂w/∂t = α∇²w − (A/τ_T)e^{−t/τ_T},  A = T_set−28
−k ∂_r w|_R = h·w(R,t)   （齐次 Robin）,   w(r,0)=0
```

做**准静态分解** `w = W(r)e^{−t/τ_T} + ŵ`：

```
∇²W + κ²W = κ²A,  κ² = 1/(α τ_T)   ⇒   W(r) = A + B·J₀(κr)
ŵ = Σₙ bₙ J₀(βₙ r/R) e^{−γₙ t}
βₙ J₁(βₙ) = Bi·J₀(βₙ),  Bi = hR/k,  γₙ = αβₙ²/R²
bₙ = A κ² Nₙ /(βₙ²/R² − κ²),  Nₙ = 2J₁(βₙ)/(βₙ(J₀(βₙ)²+J₁(βₙ)²))
```

最终

```
T(r,t) = T_air(t) + W(r)e^{−t/τ_T} + Σₙ bₙ J₀(βₙ r/R) e^{−γₙ t}
```

**这个级数只要 1~2 项就收敛到机器精度**（t=1800 s 时 γ₁t=1.53、γ₂t=13.2，n≥2 项已 <1e-8）。

## 4. t_dry 的 16 s 差异：定量归因

### 4.1 paper 的时间步是一阶的

paper 表7 给出 N=1600 时 Δt=1 s 为 205567.4、Δt=10 s 为 205553.8，
说明**长时间段用 Δt=10 s 引入了约 13.6 s 的误差**（paper 5.8 节把它当作"不可分辨"）。

本文补齐 Δt 序列（paper 格式，N=1600），并做一阶外推：

| Δt / s | 10 | 5 | 2 | 1 | 0.5 | 0.25 | 一阶外推 Δt→0 |
|---|---|---|---|---|---|---|---|
| 问题3 | 205553.9 | 205561.5 | 205566.0 | 205567.5 | 205568.2 | 205568.5 | **205568.8** |
| 问题4 | 182764.0 | 182770.8 | 182774.9 | 182776.2 | 182776.9 | — | **182777.6** |

Δt 每减半，t_dry 的增量近似减半（30.1→15.1→7.6→…）——**一阶时间误差**，
系数 c≈−1.32 s/(s of Δt)，即 `t_dry(Δt) = L − 1.32·Δt`。这解释了这 13.6 s 的来源。

### 4.2 再看空间收敛（paper 格式，全程 Δt=1 s）

| N | 800 | 1600 | 3200 | 6400 | Richardson |
|---|---|---|---|---|---|
| 问题3 | 205550.98 | 205567.49 | 205572.43 | 205573.77 | 205574.2 |
| 问题4 | 182774.10 | 182776.23 | 182776.77 | — | 182776.95 |

空间上确实二阶收敛（相邻差 16.5→4.9→1.3，比值 3.3~3.7）。

把「空间 Richardson 极限」+「Δt=1 s 的一阶时间修正(+1.32 s)」相加：

* 问题3：205574.2 + 1.3 = **205575.5 s**
* 问题4：182776.95 + 1.34 = **182778.3 s**

**与本文新解法的连续极限 205575.5 / 182778.3 完全吻合。**

### 4.3 新解法 t_dry 自身的稳定性（不是数值噪声）

| 配置 | 问题3 t_dry / s |
|---|---|
| BDF rtol=1e−9 | 205574.525 |
| BDF rtol=1e−10 | 205574.519 |
| BDF rtol=1e−11 | 205574.519 |
| BDF rtol=1e−12 | 205574.518 |
| Radau rtol=1e−9 | 205574.518 |
| Radau rtol=1e−11 | 205574.518 |
| LSODA rtol=1e−10 | 205574.519 |
| 谱 N=96 / 128 | 205575.44 / 205575.54 |

四种时间积分器 × 四个容差，结果稳定到 0.007 s；空间加密到 N=128 仍在 205575.5。
另外用 1 s 密采样的线性求交与事件求交对比，两者差 **0.000 s**（该处 dC/dt = −2.94×10⁻⁷ /s）。

### 4.4 结论

> 图片的 t_dry 是 paper 在**固定 Δt=10 s 的网格序列上做二阶 Richardson 外推**得到的值。
> 由于该序列被**一阶时间误差**主导，外推并未收敛到连续极限。
> 同一模型、同一参数下，真正收敛的答案是
> **问题3 ≈ 205 575.5 s（57.1043 h ≈ 2.3793 d）**、
> **问题4 ≈ 182 778.3 s（50.7717 h ≈ 2.1155 d）**，
> 与图片值相差 0.007~0.008%——按 paper 自己引用的有效位数（57.10 h / 50.77 h）**两者一致**。
