## 五、遇到的错误与解决（真实记录）

| # | 问题 | 解决 |
|---|---|---|
| 1 | PowerShell 向 Python 传递中文路径参数时编码错乱，`build_pdf.py` 找不到输出目录 | 改为在目标目录内写 `make.py`，用**硬编码的 UTF-8 绝对路径**调用构建函数，不再经命令行传中文参数 |
| 2 | Python 文档字符串里写了 `\ud`，被解释成 Unicode 转义导致 `SyntaxError` | 把文档字符串改为不含反斜杠的普通中文 |
| 3 | Markdown 里用了原文自定义的宏 `\ud`、`\dd`、`\bm`，MathJax 不认识，导致公式渲染成源码 | 写 `fix.py` 全局替换为 `\mathrm{d}` / `\mathbf`，并扫描未定义宏 |
| 4 | MathJax 配置里若启用 `boldsymbol` 扩展，会触发 `file://` 懒加载失败，**整个文档的公式排版静默中止** | 改用内置的 `\mathbf`，去掉 `boldsymbol` 扩展；用 `--dump-dom` + 注入错误捕获脚本定位到根因 |
| 5 | 初版守恒式数值检验用粗时间间隔做差分，有限差分误差掩盖了真实残差 | 改用 dense output 做局部差分（h = 5 s），并同时用模型自身 rhs 做机器精度对照 |

## 七、本轮技术问题记录（转 LaTeX 过程）

| # | 问题 | 解决 |
|---|---|---|
| 1 | 手写 Markdown→LaTeX 转换器时，把 `×`、`→`、`≥` 等统一替换成 `×`、`→`，**连数学段内部也替换了**，使 `2×3` 变成 `2\times3` → 报 90 处 `Missing inserted` | 重写转换器：先按 `...$`/`...` 切分，**只在文本段**做转义与 Unicode 替换 |
| 2 | `cumcmthesis.cls` 内部已加载 `hyperref`，我又写了 `\usepackage[hidelinks]{hyperref}` → `Option clash for package hyperref` | 改用 `\PassOptionsToPackage{hidelinks}{hyperref}` 放在 `\documentclass` **之前** |
| 3 | Markdown 里的 `` `\cite` `` 被转成 `\texttt{\cite}`，TeX 试图展开 `\cite` 的命令 → `TeX capacity exceeded [input stack size=10000]` | 把源文改成普通文字「cite 命令」，并在转换器中保留反斜杠不转义 |
| 4 | 用 PowerShell 管道接 `xelatex` 输出并被 `Select-Object -First` 截断 → **管道提前关闭把 xelatex 杀死**，产出 0 页 PDF | 改为 `*> pass.txt` 重定向到文件，不再截断管道 |
| 5 | 脚本里 `sys.stdout = io.TextIOWrapper(sys.stdout.buffer, ...)` 后，被包装的旧对象回收时会关闭底层 buffer，导致收尾 `print` 抛 `I/O operation on closed file` | 把构建结果写进 `_build_summary.txt` 文件而不是依赖 stdout |
| 6 | 附录编译出来只有 33 页（应 93 页） | 查明 `paper_appendix.tex` 用 `\lstinputlisting{../code/*.py}` 引源码，复制时漏了 `code/` 目录；补齐后页数一致 |
