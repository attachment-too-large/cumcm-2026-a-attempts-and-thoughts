## 四、自查与反思（本轮**更正了上一轮的两个判断**）

### 4.1 答案 X 对、我（原解答）错

1. **问题 4 的收缩归因**：答案 X 得 -60.6%（正确），原解答写 -11%（实质错误）。**已采纳。**
2. **不收缩对照实验本身**：答案 X 首创，原解答完全没有 → 归因错误无法被发现。
3. **环境口径的披露**：答案 X 明确写出拟合曲线使表 1 系统性偏高最多 0.52 ℃；原解答未披露。
4. **终止判据的严谨性**：答案 X 区分"全域最大值"与"argmax 下标"。
5. **解析解验证与收敛阶**、**外部数据交叉校验**、**参考文献**：答案 X 均更完整。

### 4.2 我对、答案 X 有偏差

1. **问题 1、2 应采用附件 1 的实测序列**：噪声只造成 0.036 ℃ 散布，拟合偏置造成 0.467 ℃ 偏移，**相差 13 倍**。
2. **问题 3、4 的两套口径不构成分歧**（本轮新增，见下）。

### 4.3 答案 X 在本轮暴露的一个新问题

答案 X 把"边界条件（用噪声数据）"的不确定度列为 +0.06 h（+0.11%）。
该数字来自"拟合 vs 原样插值"的**两种重构方式之差**。

但噪声集合实验表明：**环境测量噪声本身**造成的不确定度是 ±0.25 h（1σ≈0.44%），
即**低估约 4 倍**。原因是把"两个确定性方案之差"当成了"数据不确定度"。

**正确做法**：用**噪声实现集合**（同一 σ、多个随机种子）估计数据不确定度。

- **数据不确定度要用噪声实现集合估计，不能用两个具体方案之差代替。**
