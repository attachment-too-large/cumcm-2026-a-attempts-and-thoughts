## 1 方法要点

**建模**：取材料坐标 σ = r/R(t)。均匀仿射收缩下，Euler 方程里的材料对流速度与坐标变换
产生的对流项**精确抵消**，收缩问题化为固定域上的纯扩散问题——网格天然拉格朗日、无需动网格，
问题 4 只需把附件 2 的实测半径代入系数。

**离散**：分级谱元弱形式 Galerkin。偶数 Legendre 谱基 P_2j(2σ-1) 使质量矩阵**解析对角**
M_jj = 1/[2(4j+1)]（与解析值偏差 2×10⁻¹⁵，条件数约 4N）；柱心 1/σ 奇异由弱形式
自动消解；表面 Robin 条件以**自然边界**进入方程，离散格式因而精确满足守恒律。针对表面薄边界层
（末段仅约 4 µm）导致的谱振铃失稳，采用分级谱元；时间方向用自适应隐式 BDF/Radau，
烘干终止时刻由连续事件函数根求解定位。

## 6 模型可信度结论（摘要）

数值不确定度（约 10⁻⁵）**远小于**模型形式与数据解读的不确定度（约 3 %–6 %）。
主要不确定度来源（相对问题 3 的 t_dry）：

| 来源 | 相对影响 |
|---|---|
| 扩散系数指数读法（分式 `e^{−0.89/C}` vs 乘积 `e^{−0.89C}`） | −71 %（最大风险项） |
| 判据口径（中心 vs 平均含水率） | −38 % |
| 干基守恒形式（ρ_d 是否随 C 变化） | −3.33 % |
| 收缩模型（仅问题 4） | −6.3 % |
| 传质系数 h_m（±20 %） | +2.97 % / −1.82 % |
| 恒温段设定值（末端值 vs 平台均值） | +0.63 % |
| 环境数据平滑 | +0.45 % |
| 几何假设（端面） | −0.004 % |
| 数值离散 | <10⁻⁵ |

**三处需要提请注意的问题**（详见比对报告 §2）：
1. 题面三处扩散系数的指数均为竖排**分式**，PDF 文本抽取会压平成一行，极易误读为乘积；
   本文保留了原版面渲染截图作为证据。
2. 干基守恒的完整性依赖“干物质表观密度空间均匀”这一前提，与“刚性几何 + 经验式 ρ(C)”
   存在口径冲突，本文量化了其影响（−3.33 %）。
3. 附件 2 的收缩数据与附录 4 的传质模型在含水率域中段相差 4–13 倍，属题给数据之间的内在张力，
   本文按题目要求把附件 2 作为驱动数据直接使用，并列为不确定度来源。
