# 题面附件（第三方材料）

本目录中的文件来自竞赛主办方公开发布的题面材料，**版权归竞赛主办方所有**，
仅用于复现本包的计算结果：

| 文件 | 来源 |
|---|---|
| `附件1.xlsx` | 烘干初期各时间点（0—14400 s，每 60 s）烘房温度与水分浓度 |
| `附件2.xlsx` | 烘干过程中各时间点（0—259200 s，每 1800 s）药材半径 |
| `附件3/result1—4.xlsx` | 结果文件模板 |

`代码/hb_core.py` 按以下优先级定位附件目录：

1. 环境变量 `CUMCM_DATA_DIR`；
2. `<本包根目录>/附件`（即本目录）。

```powershell
# 使用其它位置的附件
$env:CUMCM_DATA_DIR = "D:\some\path\附件"
```
